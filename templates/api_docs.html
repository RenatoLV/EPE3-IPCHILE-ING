NexaFlow API

Documentación interactiva · FastAPI · prototipo con datos sintéticos

La interfaz Flask consume esta API para estimar demanda diaria de una ruta. El modelo y las métricas son de demostración: no representan ventas reales de Coquimbo. El esquema OpenAPI generado por FastAPI está en /openapi.json.

GET /health

Comprueba que el modelo está cargado. Devuelve 200 si está disponible o 503 si falta.

Consultar estado ahora

POST /predict

Recibe cinco variables y devuelve la demanda estimada en unidades por día. Los campos adicionales o fuera de rango producen 422.

La respuesta aparecerá aquí.

Ejemplo de solicitud

{"zona":1,"dia_semana":5,"mes":12,"promocion":1,"demanda_lag7":95.0}

La API devuelve prediccion_demanda, unidad, modelo y datos. Consulta el esquema OpenAPI para tipos y validaciones completas.
